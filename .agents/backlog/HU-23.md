# HU-23: Auto-registro de Alumnos por dominio institucional

## Cómo
Alumno

## Quiero
Registrarme usando mi email institucional.

## Para
Acceder a los cursos de mi institución sin depender de un Administrador.

## Criterios de aceptación

- El Administrador puede configurar dominios habilitados.
- Un dominio no puede pertenecer a más de una institución.
- Existe una pantalla de registro.
- Nombre, email, contraseña y confirmación son obligatorios.
- La institución se determina por el dominio del email.
- Si el dominio no está habilitado se informa el error.
- No se permite registrar un email existente.
- El rol creado es siempre Alumno.
- Se envía un email de verificación con vigencia de 24 horas.
- No puede iniciar sesión sin verificar el email.
- Puede reenviarse el enlace de verificación.
- Tras verificar el email se habilita el acceso normal.
- Se permiten hasta 5 registros por hora por IP.
- Convive con el alta administrativa de HU-9.
