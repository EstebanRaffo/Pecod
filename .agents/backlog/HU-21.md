# HU-21: Panel de analíticas para el Profesor

## Cómo
Profesor

## Quiero
Ver un panel con indicadores de mis cursos.

## Para
Conocer el alcance y la recepción de mis cursos para decidir qué contenido actualizar.

## Criterios de aceptación

- El panel muestra cantidad de alumnos inscriptos.
- El panel muestra avance promedio.
- El panel muestra calificación promedio.
- El panel muestra cantidad de reseñas.
- Se incluyen cursos publicados, despublicados y borradores.
- El avance promedio utiliza Math.round.
- Si no hay alumnos o temas, se muestra 0%.
- Si no hay reseñas, se muestra "Sin calificaciones".
- Los indicadores reflejan cambios recientes.
- Solo se muestran datos agregados.
- El Profesor solo visualiza cursos propios.
- Otros roles no pueden acceder.
- Si no existen cursos se muestra "Sin cursos para analizar".
