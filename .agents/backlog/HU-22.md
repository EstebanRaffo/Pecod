# HU-22: Recuperación de contraseña

## Cómo
Alumno, Profesor o Administrador

## Quiero
Restablecer mi contraseña cuando la olvidé.

## Para
Recuperar el acceso a mi cuenta sin depender de un Administrador.

## Criterios de aceptación

- Existe la opción "¿Olvidaste tu contraseña?".
- El sistema responde con un mensaje genérico independientemente de si el email existe.
- Se envía un enlace de un solo uso con vigencia de 60 minutos.
- Una nueva solicitud invalida la anterior.
- La nueva contraseña requiere al menos 8 caracteres.
- Debe coincidir con la confirmación.
- Los enlaces inválidos, usados o vencidos son rechazados.
- Al cambiar la contraseña se invalidan sesiones previas.
- El usuario es redirigido al login.
- Se permiten hasta 5 solicitudes por hora.
- Está disponible para los tres roles.
