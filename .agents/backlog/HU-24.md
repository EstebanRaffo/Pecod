# HU-24: Recomendación de cursos

## Cómo
Alumno

## Quiero
Recibir recomendaciones de cursos según mi historial.

## Para
Descubrir nuevos cursos relevantes sin buscarlos manualmente.

## Criterios de aceptación

- Las recomendaciones se generan semanalmente.
- Se entregan usando el sistema de notificaciones.
- Se basan en inscripciones, avance y áreas de interés.
- Solo recomiendan cursos publicados.
- Solo recomiendan cursos donde el Alumno no está inscripto.
- Cada notificación recomienda un único curso.
- Se generan hasta 3 recomendaciones por ejecución.
- No se repite una misma recomendación.
- Si no existen recomendaciones no se genera error.
- Las recomendaciones pueden marcarse como leídas.
- Si el curso deja de estar publicado se informa la situación.
- Cada Alumno visualiza únicamente sus recomendaciones.
